# PYQ Vault

This is a lightweight static website for selling previous year question papers and study materials across degrees, semesters, and exams.

## What is included

- Homepage with a clear value proposition
- Free and paid material browser
- Pricing section for `Rs. 29`, `Rs. 49`, and `Rs. 79`
- Launch tips for turning the site into a passive-income study business
- Mobile-friendly layout
- A broad-market setup with Calicut University BCA as an easy starting niche

## How to customize

1. Open `script.js`
2. Replace the demo material cards with your real products
3. Update pack names, exams, pricing, and descriptions
4. Connect buttons to your real payment or download links
5. Change the footer contact details in `index.html`

## How to open locally

Open `index.html` in your browser.

## Easy hosting options

- GitHub Pages
- Netlify
- Vercel
- Any shared hosting that supports static files
